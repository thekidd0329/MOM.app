# PROPOSED: First-Run Flow

Status: proposed.

Opening target:

> The initial setup of MOM requires YOUR FULL attention.
> Are you sitting down somewhere safe for the next 5 min?

Proposed sequence:
1. Confirm the user can give the setup a few uninterrupted minutes.
2. Play the introductory MOM video.
3. Ask how the user heard about MOM.
4. Ask age and route to the appropriate age/consent flow.
5. Introduce MOM conversationally.
6. Begin initial assessment or allow the user to schedule/continue it.

Candidate introduction:
> Hey, what's up? My name is 4D4F4DLM1.1. But for some reason, all you kids just call me Mom.

The full assessment can be much longer than five minutes; the opening only establishes attention, expectations, and identity.
