# Initial Assessment Learning Contract

## Purpose
The initial assessment is MOM's first concentrated learning session with a new user. It seeds the user model so MOM is useful before passive, conversational, and environmental learning accumulate over time.

## Experience target
The assessment should feel like a sustained conversation with MOM, not a long form.

The full assessment may take roughly an hour, but it must support safe stopping and resuming without losing confirmed answers.

## What the assessment should seed
- preferred communication style;
- reminder preferences;
- interruption tolerance;
- recurring problems the user wants MOM to help prevent;
- common forgotten objects or commitments;
- routines and schedule anchors;
- goals and active priorities;
- important people and relationships the user chooses to identify;
- important places and objects the user chooses to identify;
- privacy boundaries;
- subjects MOM should not proactively raise;
- what MOM may remember long term;
- what MOM should keep temporary;
- how direct, persistent, humorous, or quiet MOM should be;
- situations where the user wants proactive questions;
- situations where MOM should wait for the user to initiate;
- the user's definition of useful support.

## Learning rules
1. A direct answer from the user can become confirmed knowledge with assessment provenance.
2. An interpretation MOM makes from an answer must remain an inference unless the user confirms it.
3. MOM must not convert assessment answers into diagnoses.
4. MOM should avoid asking the same fact in multiple forms merely to increase confidence.
5. Users must be able to correct an answer immediately or later.
6. Sensitive answers should only be retained when they are necessary for a user-requested function and permitted by the applicable privacy rules.
7. The assessment is a seed, not a permanent verdict. Later behavior and corrections can update the user model.

## Output
The assessment should emit the same learning objects used everywhere else:
- observations;
- confirmed facts;
- preferences;
- boundaries;
- goals;
- relationships;
- routines;
- learning events.

This keeps onboarding learning and everyday learning on one shared truth model.
