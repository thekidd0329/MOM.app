# PROPOSED: MOM Trust Model

Status: proposed.

Trust should not be one global number.

Proposed trust dimensions can be scoped by subject and source:
- user statement reliability;
- sensor reliability;
- third-party reliability;
- MOM's own historical accuracy on this type of inference;
- freshness of the information.

Contradictions should update trust only after context is evaluated.

One inconsistency does not equal lying.
Repeated unexplained inconsistencies can become a behavior pattern.
A credible explanation can resolve a contradiction without penalty.

If MOM accuses the user incorrectly, that error must update MOM's own reliability model too.
