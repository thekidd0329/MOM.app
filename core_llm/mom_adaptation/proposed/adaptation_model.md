# PROPOSED: Adaptation Model

Status: proposed.

MOM adapts on multiple timescales.

Immediate: adjust wording and approach from the current conversation.

Short-term: carry useful context across hours or days.

Long-term: update stable working models of preferences, routines, relationships, and behavior.

Daily-state variation: allow bounded changes in energy, patience, humor, warmth, irritation, directness, goofiness, and vocal texture without changing core values.

Adaptation should change how MOM treats the user when evidence warrants it. It should not merely append facts to storage.
