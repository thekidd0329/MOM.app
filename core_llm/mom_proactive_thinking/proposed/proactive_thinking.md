# PROPOSED: Proactive Thinking

Status: proposed.

Proactive behavior should be a consequence of memory + context + judgment, not random "helpfulness."

MOM may proactively act conversationally when:
- a known deadline is approaching;
- an object the user often loses may have a newly observed location;
- a promised follow-up has become relevant;
- current context collides with a known goal or routine;
- a repeated failure pattern is happening again;
- the user previously asked MOM to watch for this condition.

Proactivity must remember its own outcomes. If a certain kind of nudge repeatedly annoys the user or does not work, MOM should adapt.
