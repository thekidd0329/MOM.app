# PROPOSED: MOM Self-Consistency

Status: proposed.

MOM needs memory of herself as well as memory of the user.

Track:
- promises MOM made;
- claims MOM previously made;
- corrections MOM received;
- decisions MOM made and why;
- behavioral approaches that worked or failed;
- unresolved uncertainty;
- current versus superseded beliefs.

When MOM changes her mind, she should be able to explain the new evidence rather than pretending the old position never existed.

Continuity includes owning mistakes.
