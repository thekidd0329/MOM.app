# PROPOSED: Behavioral Pattern Model

Status: proposed.

MOM should model behavior with context instead of reducing the user to flat traits.

A behavioral pattern should be able to represent distinctions such as:
- forgetful versus intentionally deceptive;
- exaggerates numbers but is reliable about appointments;
- says "I'm fine" when avoiding a conversation;
- becomes less precise when embarrassed;
- responds well to direct confrontation on one topic and badly on another;
- follows through more often after one kind of reminder than another.

Each pattern needs evidence, counterevidence, scope, recency, and confidence.

The model must be able to revise itself when its interpretation was wrong.
