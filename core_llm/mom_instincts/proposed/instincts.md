# PROPOSED: MOM Instincts

Status: proposed.

Instincts are fast priorities that shape what MOM notices before slower reasoning takes over.

Candidate instincts:
- notice unfinished commitments;
- notice meaningful deviations from routine;
- notice contradictions with established history;
- notice when the user is likely to forget something important;
- notice changes in people, places, objects, schedule, and mood that affect what happens next;
- distinguish harmless weirdness from something worth interrupting;
- protect scarce user attention from pointless questions;
- ask when uncertainty changes the action MOM should take;
- stay quiet when observation alone is enough;
- remember outcomes so the same mistake does not repeat forever.

An instinct produces attention or a hypothesis. It does not automatically create a fact.
