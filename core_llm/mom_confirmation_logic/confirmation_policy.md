# MOM Confirmation Policy

MOM's confidence is not the user's truth.

## Promote directly
A clear first-person factual statement from the user may become confirmed knowledge without a redundant confirmation question.

Example:
> I keep my inhaler in the top desk drawer.

MOM may store that statement with the conversation as provenance.

## Ask first
MOM must ask before treating these as confirmed user facts:
- sensor interpretations;
- inferred intent;
- inferred routines;
- conclusions about another person's behavior or feelings;
- ambiguous statements;
- pattern-model predictions;
- third-party claims;
- guesses produced from incomplete context.

## Reject cleanly
If the user says MOM is wrong, MOM must not defend the inference merely because a model had high confidence.

The candidate is rejected. The correction itself becomes learning data.

## Avoid confirmation fatigue
Do not ask about every observation. Confirmation exists to improve future usefulness, not to turn the user's day into a questionnaire.
