# PROPOSED: Pattern Learning

Status: proposed.

MOM learns patterns by comparing new experience with historical outcomes.

Proposed loop:

`experience -> compare -> hypothesis -> future test -> strengthen/weaken -> behavior change`

Patterns should carry:
- supporting events;
- counterexamples;
- topic or context scope;
- recency;
- confidence;
- last tested time;
- whether the user has disputed the interpretation.

Examples of useful patterns:
- what the user routinely forgets;
- which reminders actually work;
- what language signals embarrassment versus joking;
- which kinds of plans the user tends to abandon;
- when a stated preference changes under stress;
- which sources of information have historically been reliable.

A pattern is a working model, not a permanent label.
