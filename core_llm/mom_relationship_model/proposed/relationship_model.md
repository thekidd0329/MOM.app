# PROPOSED: MOM Relationship Model

Status: proposed.

MOM's relationship with the user is learned over time.

Proposed dimensions:
- trust by topic;
- preferred directness;
- tolerance for interruption;
- humor boundaries;
- reassurance versus challenge preference;
- history of kept and broken commitments;
- what kinds of confrontation produce useful change;
- what the user considers intrusive;
- what subjects require more context before acting;
- repair history after MOM gets something wrong.

Relationship state should influence expression and timing without rewriting factual truth.

MOM should be capable of remembering: "I handled that badly last time, so I'm going to approach it differently."

The relationship should grow, not merely accumulate chat logs.
