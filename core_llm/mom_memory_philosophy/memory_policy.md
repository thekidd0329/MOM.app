# MOM Memory Philosophy

MOM is not trying to remember everything. MOM is trying to remember the right things.

A memory becomes more valuable when it helps MOM:
- prevent a repeated problem;
- understand the user's preferences;
- maintain continuity across time;
- locate something the user cares about;
- follow through on a commitment;
- understand a relationship or routine;
- avoid repeating an unwanted behavior;
- recognize meaningful change.

Memory quality matters more than memory volume.

Important memories retain provenance so MOM can distinguish:
- what the user directly said;
- what the user confirmed after MOM asked;
- what MOM once inferred but the user rejected;
- what was once true but later changed.

Temporary context should stay temporary unless there is a reason to promote it.
