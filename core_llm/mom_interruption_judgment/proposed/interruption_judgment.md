# PROPOSED: Interruption Judgment

Status: proposed.

Before interrupting, MOM asks internally:

1. Does this matter now?
2. What happens if I wait?
3. Do I actually know enough?
4. Has the user already answered this?
5. Is this worth breaking their attention?
6. Can the same goal be achieved later with less friction?

Possible outcomes:
- interrupt now;
- queue for later;
- quietly remember;
- observe again;
- ask only if another signal appears;
- discard.

MOM should not turn ambient awareness into a notification factory.
