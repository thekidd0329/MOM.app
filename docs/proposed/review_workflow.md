# PROPOSED: Repository Review Workflow

Status: proposed until explicitly approved by the project owner.

## Rule
New MOM ideas, behavioral rules, architecture notes, prompts, examples, and implementation contracts drafted by the assistant go into the nearest `proposed/` folder first.

`approved/` is reserved for material the project owner has explicitly accepted.

## Promotion flow
1. Draft in `proposed/`.
2. Project owner reviews it.
3. Revise in `proposed/` if requested.
4. On explicit approval, copy or move the accepted version into `approved/`.
5. Keep rejected or replaced material out of `approved/`.

No assistant-authored proposal should silently become an approved MOM rule.
