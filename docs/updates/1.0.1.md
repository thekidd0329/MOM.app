## Canonical artwork

The exact trademarked `2546.png` is the visual source of truth.

Rules:
- Do not redraw it.
- Do not regenerate it.
- Do not trace or vectorize it.
- Do not recolor it.
- Do not procedurally approximate it.
- Do not silently substitute another orb.
- Do not add a fallback orb.

The production path is:

`apps/mom_native/assets/ui/2546.png`

The artwork itself already contains the canonical glowing `Listening…` treatment, so 1.0.1 does not draw a second copy of that status text over the image.

## Home interface

The canonical artwork appears first as the dominant visual. The app then powers the controls into place with electrical strikes originating at the visible plasma-globe area:

1. microphone — top-left
2. settings — top-right
3. `Version 1.0.1` — bottom-left
4. keyboard/text — bottom-right

Each strike uses a purple outer glow, bright core, small electrical branches, and an impact bloom. The target control scales/flashes into place on impact. The zap painter is separate from the image and never draws the orb.

MOM reply captions/history remain available beneath the artwork. Text entry, microphone interaction, settings, and long-press diagnostics remain wired to their existing callbacks.

## Fidelity and performance

1.0.1 prioritizes visual fidelity over supporting weak hardware. The entrance may use layered lightning and bloom even if low-end devices animate it less smoothly.

However, expensive animation work must not continue without a visible purpose. The electricity controller stops after the entrance sequence so normal UI interaction has the full frame budget available.

## Release protection

`tools/verify_mom_ui_asset.py`
- requires `apps/mom_native/assets/ui/2546.png`
- verifies PNG signature
- refuses packaging when the canonical asset is absent or invalid
- prints SHA-256 and byte size when present so the accepted binary can be pinned later

`tools/verify_mom_1_0_1_ui_contract.py`
- requires direct `Image.asset` use of `assets/ui/2546.png`
- requires the control-zap painter
- requires visible `Version 1.0.1`
- requires mic/settings/keyboard controls
- rejects `_ElectricOrbPainter`
- rejects `_PlasmaOrbPainter`
- rejects silent `errorBuilder` fallback behavior
- requires `version: 1.0.1+9`
- requires `assets/ui/` packaging

`.github/workflows/mom-native.yml` runs both checks before Flutter analysis/build work.
