## Live plasma orb

Production implementation:

`apps/mom_native/android/app/src/main/kotlin/app/mom/mom_native/PlasmaOrbView.kt`

Flutter registration:

`apps/mom_native/android/app/src/main/kotlin/app/mom/mom_native/MainActivity.kt`

Platform-view name: `mom/plasma_orb`.

Matt's supplied implementation continuously redraws with `postInvalidateOnAnimation()` and includes eight primary electrical branches, randomized path jitter and surge thickness, a purple blurred outer glow, white-hot electrical cores, and four moving rim arcs.

## Home interface

The live orb is constrained to a square approximately 64% of available phone width with an upper size cap, preserving a circular form rather than the oversized/oval mockup.

Startup order:

1. live plasma orb establishes itself
2. microphone zaps into top-left
3. settings zaps into top-right
4. `Version 1.0.1` zaps into bottom-left
5. keyboard/text control zaps into bottom-right

MOM reply captions/history, text input, microphone behavior, settings, and diagnostics remain wired.

## Settings repair

The previous settings route returned immediately when the cloud sync client was null, making the gear appear dead during sync/bootstrap trouble.

1.0.1 opens local settings whenever local configuration is available. Only the cloud-dependent cross-device row disables when sync is unavailable.
