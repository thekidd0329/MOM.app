# MOM 1.0.1

Status: YELLOW — UI implementation in progress on `release/1.0.1-ui`

## Primary goal
Make the production MOM interface match the intended trademarked design instead of the current procedurally painted orb.

## Canonical artwork
- Use the exact trademarked `2546.png` artwork as the visual source of truth.
- Do not redraw, regenerate, trace, vectorize, procedurally recreate, recolor, or approximate the artwork.
- Do not replace it with a Flutter `CustomPainter` orb.
- Preserve its original plasma structure, pink/violet electricity, bright center, glow, reflection, and overall composition.

The canonical `2546.png` has been located in the MOM File Library and visually confirmed. The GitHub connector cannot directly transfer File Library binary assets into the repository, so the exact binary still must be placed at the registered asset path before this branch can be considered merge-ready.

## Home screen layout
- Black background in dark mode; white background in light mode.
- Exact `2546.png` centered as the dominant visual.
- Status text centered above the orb, including `Listening...`, `Thinking...`, and speaking/idle states as appropriate.
- Microphone control: top-left.
- Settings control: top-right.
- Version label: bottom-left.
- Keyboard/text control: bottom-right.

## Signature entrance animation: lightning-zapped controls
The interface should feel as though the plasma orb powers the UI into existence.

1. The exact `2546.png` artwork appears first.
2. Lightning activity builds from the orb.
3. A visible electrical strike travels from the orb toward a control location.
4. The target control flashes into place on impact with a brief glow/bloom.
5. Repeat for the remaining controls and status text in a deliberate sequence.
6. Once the controls are established, the artwork remains the visual anchor and normal MOM interaction begins.

The electrical animation is implemented as a separate overlay painter. It does not draw or replace the orb itself.

## Visual fidelity vs performance
For 1.0.1, visual fidelity wins. Do not significantly reduce the effect merely to optimize older/slower phones. Full glow, layered strikes, bloom, and timing are allowed even if the entrance animation is heavier on low-end hardware.
