# MOM 1.1.0

Status: YELLOW — unified integration and artifact verification in progress

## Release goal

MOM 1.1.0 combines the current plasma UI, the completed ten-phase voice engine, and the server-authoritative runtime migration in one release line.

## Source ownership

- Device: plasma UI, microphone, STT, Kokoro/CrispASR native runtime, local conversation history, installation credentials, onboarding preferences, and offline behavior.
- Supabase: canonical prompt/model authority, bounded runtime settings, routing metadata, privacy/runtime versions, and feature switches.
- Hugging Face: hosted model inference behind Supabase; provider credentials never enter the APK.

## Build rule

One source commit produces one universal Android APK. Unit/static checks run before that build. APK identity/native-library verification and emulator UI verification both consume the same uploaded APK; no workflow writes proof commits back into a source branch.

## Completion gates

1. Flutter analysis and complete unit suite pass.
2. Server-authority and privacy contracts pass.
3. Universal APK contains the required ARM64 and x86_64 CrispASR/Kokoro dependency closure.
4. APK package/version/commit identity is verified.
5. The exact uploaded APK completes onboarding and renders the home/settings UI in the emulator.
6. Physical-device microphone → STT → brain → Kokoro → speaker proof passes before release promotion.
